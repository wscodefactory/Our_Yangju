# 한눈에 양주 | Our Yangju

헤매는 시간 없이, 모두가 함께하는 양주.
외국인 주민이 받은 안내를 모국어로 이해하고 바로 할 일까지 잇는 AI 생활·행정 길잡이 — 2026 양주시 미래인재 AI 공모전 12팀 프로토타입.

## 실행
`index.html` 하나로 동작하는 단일 페이지 웹입니다. 브라우저(크롬 권장)로 열면 됩니다.

- claude.ai 아티팩트에서 열면 AI 기능(고지서 사진 읽기·질문 분류·번역)과 공유 저장소가 동작합니다.
- 일반 브라우저나 GitHub Pages로 열면 AI 연결이 없어 자동으로 **시연 모드**(미리 계산한 예시 값)로 동작합니다.

## 화면 구성
1. 내 언어 선택: 한국어·English·中文·Tiếng Việt·नेपाली
2. 용건 선택: 시청·주민센터에 왔어요 / 받은 종이가 있어요 / 양주에서 살기
3. 행정 업무 6종 카드: 장소·기한·준비물 + 창구에 보여줄 한국어 한 줄
4. 고지서 할 일 카드: 개인정보 가림 → 금액·기한 추출 → 원문 대조 → 납부 연결(위택스)
5. 담당자 창구 모드: 주민 언어 ↔ 한국어 나란히, 안내문 등록

## 코드 구조
단일 HTML 안에 스크립트 3묶음이 있습니다.

| 묶음 | 내용 |
|---|---|
| 기본 | 화면 데이터·렌더링·화면 이동, 확장 훅 `EXT[화면키]`·`ACT[동작]` |
| 문서 찍기 | 촬영·가림·AI 추출·할 일 카드(5개 언어)·추가 질문(지방세 시나리오 20개)·담당자 안내문 등록 |
| 언어·업무 | 언어 선택, 행정 업무 6종, 양주에서 살기, 담당자 창구 모드, 화면 문구 즉시 번역 |

- 페이지 권한(claude.ai): `sample`(AI 호출), `db`(컬렉션 `benefits`), `user`
- 브라우저 저장: `hy-lang`, `hy-cl`, `hy-mine`, `hy-newb`

## 원칙
- AI는 세액·자격을 판정하지 않습니다. 금액·기한은 추출값 그대로 보여주고 원본 확인을 안내합니다.
- 가린 이미지만 전송하고 원문은 저장하지 않습니다. 납부 링크는 공식 주소만 씁니다.
- 화면의 업무 안내는 일반 법령 기준 예시이며, 양주시 창구별 접수 범위는 확인 중입니다. 번역은 AI 초안으로 원어민 검토 전입니다.
