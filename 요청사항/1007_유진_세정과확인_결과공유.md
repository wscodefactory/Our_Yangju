# [유진] 세정과 추가 확인 결과 공유 (2026.10.7)

세정과에서 내부 부담을 이유로 자료 협조와 출처 표기를 하지 않았으면 한다고 해서, 세정과 내용은 모두 빼고 공개자료·법령·실물·직접 테스트로 대체했습니다.

## ① 외국인 체납 규모
- 양주시 외국인 체납 수치는 공개자료에 없음
- 대체: 전국 외국인 지방세 체납 466억(2024, 행정안전부 국정감사 자료 보도), 비슷한 규모인 안성시 외국인 1,155명 체납

## ② 6개 언어 안내문 원본
- 원본 확보 못 함. "6개 언어"는 원문 확인 전이라 발표에서는 쓰지 않는 것을 제안
- 대신 재산세 외국어 고지서(영·일·중) 원본을 양주시 보도자료 첨부(2026.9.22)로 확보

## ③ 시나리오 검수
- 세정과 검수는 불가. 대신 법령 원문·위택스·고지서 실물로 문구를 직접 검증
- 기한 후 3% 가산, 세목별 세액 45만 원 이상만 매월 0.66% 추가 (지방세기본법 제55조, 시행령 제34조) → 문구는 기준만 보여주고 금액별 판정은 하지 않음
- 위택스에서 전자납부번호로 로그인 없이 조회 가능 → 행동카드에 번호 복사 + 경로 안내 제안

## ④ 기존 세무 챗봇 외국어 테스트 (직접 테스트, 2026.10.6)
- 위택스봇: 테스트한 영어·베트남어·네팔어 질문을 인식하지 못함
- 서울시 이지: 테스트한 영어 질문을 인식하지 못함
- 국세청 AI 챗봇: 세 언어를 이해하지만 한국어로만 답함
- 본선 "AI·데이터 활용(25점)"과 질의응답의 근거로 활용 가능

## 팀 요청 사항
- 본선 자료에서 "세정과 유선 확인" 표현은 모두 빼 주세요
- 실행안의 "세정과(주관·검수)"는 "관련 세무 부서(안)"로 일반화 제안
- 프로토타입 세금 문구는 「1007_유진_프로토타입문구」 기준으로 맞춰 주세요 (진우·웅선)
