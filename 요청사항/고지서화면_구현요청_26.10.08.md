# 고지서 화면 구현 요청 (웅선 님께)
 
작성: 김유진 / 2026.10.8
 
웅선 님, 프로토타입 개발하시느라 고생 많으십니다.
오늘 멘토링 의견("고지서를 읽은 뒤 실제 납부까지 이어지게")을 반영해, **고지서 화면에서 시연에 꼭 필요한 부분**만 정리했습니다.
 
---
 
## 시연 흐름 (발표: 유진, 약 2분)
 
> 한국어 자동차세 고지서를 받은 베트남 출신 주민이, 내 언어로 이해하고 납부까지 마치는 흐름
> (베트남은 양주시 등록외국인 1위 국적, KOSIS 2025)
 
| 장면 | 화면 | 보여주는 것 |
|---|---|---|
| 1 | 고지서 촬영 → 이름·주소 가리기 | 개인정보 보호 |
| 2 | 읽은 금액·기한을 고지서와 나란히 확인 | AI 인식 + 사람 확인 |
| 3 | 베트남어 행동카드 → 언어 버튼으로 네팔어 전환(2~3초) | 내 언어로 이해, 번역 앱(파파고)도 지원하지 않는 언어까지 |
| 4 | 입금 계좌번호·금액 복사 → 은행 앱으로 송금 | 실제 납부로 연결 |
| 5 | (짧게) 모르는 질문 → 1345 + 한국어 메모 | 범용 AI와의 차이 |
| 6 | [납부 완료] → 이 휴대폰에 납부 기록 저장(선택) | MY 기능 |

## 요청 ① 고정 문구를 미리 번역해 넣기
 
**왜 필요한가요?**
지금은 AI 연결이 없을 때 베트남어·네팔어를 골라도 할 일·납부 방법은 한국어, 질문 버튼은 영어로 나옵니다. 아래 문구는 **매번 같은 고정 문구**라서, 표의 번역을 그대로 화면 문구로 넣어 두시면 **AI 없이도 시연 화면이 항상 해당 언어로** 나옵니다.
 
- `[ ]` 안은 고지서에서 읽은 값으로 바뀌는 자리입니다.
- 번역은 AI 초안입니다. 시연 전에 원어민 확인을 받아 보겠습니다. 화면의 "AI 번역 초안" 안내는 그대로 두시면 됩니다.

※ 위택스 메뉴 이름([납부], [납부대상조회])은 실제 위택스 화면이 한국어라서 **한국어 그대로** 두었습니다. 사용자가 화면에서 같은 글자를 찾을 수 있게 하기 위해서입니다.
 
**[위택스 연결 제안]** 지금 "위택스" 버튼은 위택스 첫 화면으로 연결됩니다. 가능하시다면 **[납부대상조회 → 전자납부번호] 화면으로 바로 연결**되도록 해 주시면, 외국인 사용자가 한국어 메뉴를 다시 찾지 않아도 됩니다. 버튼을 누를 때 **전자납부번호가 자동으로 복사**되면 더 좋겠습니다. 다만 해당 화면의 주소가 로그인 없이 바로 열리는지는 제가 확인하지 못했습니다. 바로 열리지 않으면 지금처럼 첫 화면으로 두고 위 경로 안내만 유지해 주셔도 충분합니다.

## 요청 ② 납부 방법 1순위를 "은행 앱 가상계좌 이체"로
 
**왜 필요한가요?**
위택스는 한국어 화면과 본인 인증(비회원도 필요)이 장벽입니다. 반면 은행 앱은 이미 본인 인증이 된 상태이고 외국어를 지원합니다. KB국민·NH농협 앱은 베트남어·네팔어로 이체 메뉴까지 표시되는 것을 확인했고(10/8 직접 확인), 신한은행도 외국인 전용 앱을 16개 언어로 운영합니다(2025.12 공식 발표).
 
**행동카드 구성 제안 (위에서 아래 순서)**
 
1. **고지서 요약:** 자동차세(12월분) / 납부 금액 / 납부 기한 / 납부 기한까지 ○일 남음
2. **지금 할 일: 은행 앱으로 송금하기 (가장 쉬운 방법)**
   - 맨 위에 입금 은행 / 입금 계좌번호 / 송금 금액을 한 상자로 보여 주기
   - 표 C의 1~7단계를 번호 목록으로
   - 1단계 옆에 **[계좌번호 복사]**, 5단계 옆에 **[금액 복사]** 버튼
   - 3단계의 받는 은행 이름은 고지서에서 읽은 가상계좌 은행으로 표시
   - 맨 아래에 사기 주의 한 줄
3. **[납부 완료] 버튼** → "납부 기록을 이 휴대폰에 저장할까요?" (선택, 저장 시에도 사진·이름·계좌번호는 저장하지 않음)
4. **다른 납부 방법** (접어 두기): 위택스(카드), ATM, ARS
5. **납부 기한이 지나면:** 표 E 문구
6. **[추가 질문] / [상담 연결]**
이렇게 하면 시연 장면 4에서 "복사 → 은행 앱으로"가 한눈에 보이고, 위택스는 카드로 내고 싶은 분을 위한 선택지가 됩니다.
 
**화면 디자인 참고 제안 (가능하신 범위에서만)**
 
웅선 님이 이미 화면을 잘 잡아 주셔서, 가독성 면에서 참고하실 만한 점 두 가지만 조심스럽게 제안드립니다.
 
1. **핵심 정보와 단계를 한눈에:** 납부 금액·납부 기한·남은 날짜는 지금처럼 크게 두고, 7단계는 **번호를 큰 원으로 표시**해 한 줄에 한 단계씩 보이게 하면 어떨까요? 복사 버튼은 해당 줄 오른쪽에 바로 붙이고, 누르면 "복사 완료"가 잠깐 뜨면 은행 앱으로 넘어가기 전에 안심할 수 있을 것 같습니다.
2. **작은 회색 글씨의 대비:** 어두운 배경 위의 작은 회색 글씨(예: 하단 안내, 근거 표기)가 휴대폰에서 조금 흐리게 보였습니다. 본문 안내만이라도 글자를 한 단계 밝고 크게 하면 시연 화면과 발표자료 캡처에서 더 잘 읽힐 것 같습니다.
