## 1. UI/UX 전면 개편 (양주시 디자인시스템 적용)

근거 문서: 「한눈에양주_UIUX_개선방향」, 「양주시_디자인시스템_YangjuDS」, 「한눈에양주_UI개선 (참고용).html」

| 영역 | 내용 |
|---|---|
| 디자인 | 양주시 CI 헤더, Yangju Green 기반 토큰, 밝은 테마 하나, Pretendard·Noto Devanagari, 480px 한 열 |

| 하단 고정 바 | 업무 상세(1345 전화 / 직원에게 보여주기), 고지서 확인(할 일 보기), 고지서 결과(Wetax / 납부 완료), 혜택 상세(저장 / 문의 메모) |

## 2. 고지서 화면 구현 요청 반영

근거 문서: 「고지서화면_구현요청_26.10.08」

- **은행 앱 송금 1순위**: 요약 카드 → 지금 할 일(입금 은행·계좌·금액 상자, 7단계, 1·5단계 복사 버튼, 사기 주의) → 다른 납부 방법(접힘: 위택스 카드·ATM·ARS) → 기한이 지나면(3%·0.66%) 순서
- **납부 완료 → 납부 기록**: "이 휴대폰에 저장할까요?" 선택. 세목·금액·기한·날짜만 저장, 사진·이름·계좌는 저장 안 함. 고지서 화면에서 보기·삭제
- **문구**: A·B·C·D·E·F·G표 그대로 반영 (촬영 화면, 확인 화면 "고지서 내용과 일치하나요?"·"다른 부분은 직접 수정하세요", 요약 "납부 기한까지 n일 남음", 질문 10개 답변, 상담 탭 한국어 메모·메모 복사)
- 샘플 고지서의 "QR 납부(가상)" 삭제

## 4. 번역 점검

- 자동 점검(문구 240여 개 + 콘텐츠 전체): 빈 칸 0, 자리표시자 불일치 0. 다른 언어에 한글이 남은 곳은 위택스 메뉴명(의도)과 고지서의 은행명뿐
- 사진 경로 문구 12개(가리기 안내, 읽는 중, 실패 안내 등)가 한국어·영어만 있어 5개 언어로 추가
- 중국어 줄바꿈 오류(어절 단위 규칙이 적용돼 어색하게 끊김) 수정, 행사 기간 서식을 언어별로 통일
- 납부 기한 입력을 브라우저 달력(기기 언어 고정) 대신 연·월·일 세 칸으로 교체 → 5개 언어 라벨

## 5. 사진 읽기 속도

같은 고지서 이미지로 실측한 결과입니다.

| 모델 | 결과 |
|---|---|
| gemini-3.8-flash (기존) | 무료 할당량 초과(429)로 거부되거나 응답까지 230초 |
| gemini-3.5-flash-lite (변경) | 1.5~2초, 금액·기한·전자납부번호·가상계좌 정확 |

- 모델을 gemini-3.5-flash-lite로 변경(무료 티어, 비용 0원). "생각(thinking)" 끔, 전송 사진 긴 변 1200px·품질 0.8, 응답 JSON 축소
- 앱 안에서 사진 업로드 → 가리기 → 읽기 → 확인까지 1.6~2.1초
- 측정 중 발견한 버그 수정: AI가 읽은 뒤 확인 화면으로 못 가고 "읽는 중"에 남던 문제(화면 전환이 브라우저 히스토리와 경쟁)

## 6. 기타

- 음성 읽어주기: 화면을 나가거나 시트를 닫으면 멈춤
- 사진 읽기 진입: 키가 있으면 사진 버튼, 없으면 "AI 키 넣고 사진 읽기 켜기" 버튼(개편 전 방식). 안내 문구도 "키가 없어 쓸 수 없음"으로 정정
- 배포 워크플로: 모델을 gemini-3.5-flash-lite로 지정. 키는 저장소 Secrets `VITE_GEMINI_API_KEY`에 등록하면 다음 배포부터 자동 포함

## 시연 전 확인 사항

- **AI 키**: 배포본에는 키가 없습니다. 시연 기기에서 "AI 키 넣고 사진 읽기 켜기"로 한 번 넣거나, GitHub Secrets에 등록 후 재배포. 결제 미연결(무료 티어) 키만 사용
- **음성**: 베트남어·네팔어 읽어주기는 기기 음성 데이터가 있어야 합니다. 안드로이드는 Google 음성 서비스에서 두 언어를 설치, 아이폰은 네팔어 음성이 없음
- **실물 테스트**: 87,500원 가상 고지서(내장 샘플 143,000원과 구분)로 사진 읽기를 한 번 확인
- **번역**: 유진 님 표에 없던 영어·중국어 문구(은행 송금 7단계, 다른 납부 방법, 공식 안내 등)는 AI 초안입니다. 외국어 화면 하단에 "AI 초안" 표시가 있습니다
