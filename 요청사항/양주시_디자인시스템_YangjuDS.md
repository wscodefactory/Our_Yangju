# Yangju DS: 「한눈에 양주(Our Yangju)」 디자인 시스템 v0.1

양주시 CI(시정마크) 색상 규정과 범정부 UI/UX 디자인 시스템(KRDS)의 원칙을 바탕으로 만든 서비스 전용 디자인 시스템입니다. 「한눈에 양주」는 휴대폰 브라우저에서 쓰는 모바일 웹앱이므로, 모든 규칙은 휴대폰 한 손 사용을 기준으로 합니다.
기준 구현물은 `한눈에양주_UI개선_프로토타입.html`이며, 아래 토큰과 컴포넌트는 모두 그 파일 안에 CSS 변수로 들어 있습니다.

작성일: 2026년 10월 8일

## 1. 브랜드

### 1.1 로고(CI)
- 양주시 공식 시정마크를 그대로 씁니다. 영문 워드마크 `YangJu`, 국문 `양주시`, 녹색과 주황 잎 심벌로 이루어져 있습니다.
- 출처는 양주시청 누리집의 양주소개 > 양주시상징 > 시정마크(CI) 메뉴이고, 담당은 총무과 행정지원팀(031-8082-5213)입니다.
- CI 규정에 따라 형태, 색상, 조합은 바꾸지 않습니다. 이 서비스도 원본 PNG를 손대지 않고 넣었습니다.
- 홈 화면 앱 바에 높이 40px(화면 폭 420px 이하에서는 34px)로 두고, 홈 푸터에는 28px로 한 번 더 둡니다. 하위 화면 앱 바에는 로고 대신 뒤로 버튼과 화면 제목이 들어갑니다.
- 로고 둘레에는 심벌 높이의 4분의 1 이상을 비웁니다. 로고 오른쪽에는 1px 구분선을 두고 서비스명 「한눈에 양주」를 붙입니다.

> 주의: 운영에 반영하기 전에 총무과에 CI 사용 승인과 고해상도 원본(AI 또는 SVG)을 요청해야 합니다. 지금 프로토타입은 누리집에 게시된 225×154 PNG를 씁니다.

### 2.3 색 사용 규칙
- 이 서비스는 밝은 테마 하나만 씁니다. 기기 설정에 따라 화면이 달라지면 안내 자료나 캡처와 실제 화면이 어긋나기 때문입니다.
- 상태는 색에만 맡기지 않고 글자로도 알려 줍니다. 가능하면 아이콘도 함께 둡니다. 기존 서비스의 색 점 범례는 글자 배지로 바꿨습니다.
- 한 화면에 주 버튼(`primary`)은 하나만 둡니다.
- 아이콘 상자의 색은 영역별로 고정합니다. 업무는 그린, 고지서는 오렌지, 혜택은 앰버, 생활은 블루, 긴급은 레드입니다.

## 3. 타이포그래피

### 3.1 서체 (문자 체계별)
| 언어 | 1순위 | 대체 |
|---|---|---|
| ko, en, vi | Pretendard Variable (KRDS 권장 서체, 베트남어 성조 부호 지원) | Apple SD Gothic Neo, Malgun Gothic, system-ui |
| zh | Pretendard(라틴 문자와 숫자) | PingFang SC, Microsoft YaHei, Noto Sans SC |

- 기존에 쓰던 `Do Hyeon`은 장식용 제목 서체라 공공 서비스 분위기와 맞지 않고, 한글 말고는 지원하는 문자가 없어 뺐습니다.
- 데바나가리 문자는 위아래 획이 길어서 네팔어 화면은 `line-height: 1.75`로 줄 간격을 넓힙니다.
- 한국어 문장은 `word-break: keep-all`로 어절 단위로 줄을 바꿉니다.

| H1 | 1.375rem (22px) | 700 | 하위 화면 제목 |

### 3.3 큰 글씨 모드
- 헤더의 Aa 아이콘 버튼(`aria-pressed`)으로 켜고 끕니다. `html.big { font-size: 118.75% }`라서 rem으로 정한 모든 크기가 같이 커집니다.
- 설정은 기기(localStorage)에 저장합니다. 저장이 막힌 환경에서도 기본 크기로 문제없이 동작합니다.

### 4.1 모바일 웹앱 규칙
| 항목 | 규칙 |
|---|---|
| 홈 화면 추가 | `mobile-web-app-capable`, `apple-mobile-web-app-capable`, `apple-mobile-web-app-title`, `theme-color`(#FFFFFF), `color-scheme: light` 메타 태그 |
| 안전 영역 | `viewport-fit=cover`와 `env(safe-area-inset-*)`를 헤더, 플로팅 버튼, 시트, 푸터에 반영 |
| 높이 | 시트 최대 높이와 앱 최소 높이는 `dvh` 단위를 써서 주소창이 접히고 펴져도 잘리지 않게 함 |
| 터치 | `-webkit-tap-highlight-color: transparent`, `touch-action: manipulation`(더블탭 확대 방지), 눌림 상태는 `:active` 배경색 |

| 전화 | 번호는 `tel:` 링크로 바로 걸기. `format-detection: telephone=no`로 금액 같은 숫자가 전화번호로 잡히지 않게 함 |

## 5. 아이콘

- 24px 격자, 선 두께 1.9, 끝이 둥근 선형 아이콘(Lucide 계열 형태)을 씁니다. 장식용 아이콘에는 `aria-hidden`을 붙입니다.

**헤더 아이콘 (모든 화면 공통)**

| 아이콘 | 기능 | 레이블 (ko / en) | 비고 |
|---|---|---|---|
| 지구본 | 언어 선택 시트 열기 | 언어 선택 / Language | aria-label에 현재 언어 이름을 넣음 |
| Aa | 글자 크게 켜고 끄기 | 글자 크게 / Larger text | `aria-pressed` |
| 북마크 | 저장한 혜택 보기 | 저장한 혜택 / Saved benefits | 저장 개수 배지(오렌지). 저장 화면에서는 `aria-current` |
| 왼쪽 화살표 | 뒤로 가기 | 뒤로 / Back | 페이지 제목 왼쪽 |
| 오른쪽 꺾쇠 | 하위 화면으로 이동 | | 글자 화살표는 쓰지 않음 |
| 말풍선 | AI 상담 열기 | AI 상담 / Ask AI | 플로팅 버튼, 아이콘과 글자를 함께 표시 |

- 업무 아이콘: 관공서, 문서, 하트(혜택), 집(생활), 신분증, 의료 십자, 자동차, 버스, 서류가방, 사이렌, 휴지통, 달력, 위치 핀, 전화, 복사, 외부 링크, 스피커, 전체 화면.
- 쓰지 않는 것: 글자 한 자를 넣은 캐릭터 아바타(기존 "무"), 이모지나 특수문자를 아이콘처럼 쓰는 방식(별표, 연필, 글자 화살표).

| 버튼 | primary, secondary, ghost, sm | primary는 화면당 하나. 아이콘은 글자 왼쪽 |
| 칩 | 대상 고르기 필터 | `aria-pressed`. 준비 중인 항목은 "(준비 중)"을 붙임 |
| 세그먼트 탭 | 2~4개 탭 | `role=tablist`, `aria-selected`. 긴 화면 나누기(고지서 결과, 혜택 상세, 둘러보기), 단계 선택, 예/아니요/모름 |
| 배지 | 단위(중앙정부, 경기도, 양주시), 상태(가능성 높음, 확인 필요), 예시 | 반드시 글자를 넣음. 색 점만 두지 않음 |
| 안내 상자 | info, warn, green | 아이콘과 문장. 경고는 노란 왼쪽 선 |
| 체크리스트 | 진행률 글자, 막대, 체크박스 | 준비물 목록. 체크하면 취소선 |
| 직원용 전체 화면 | 큰 한국어 문장(`lang=ko`), 사용자 언어로 된 뜻, 한국어 듣기 버튼, 닫기 | 하단 바의 '창구 직원에게 보여주기'로 엶. 한국어를 그대로 둠 |
| 단계 표시 | 4칸 진행 막대 | 고지서 흐름: 사진 찍기, 개인정보 가리기, 내용 확인, 할 일 |
| 요약 카드 | 금액과 기한 2열(D-day 배지, 원문 표기), 읽어주기 아이콘, 연체 경고 한 줄 | 고지서 결과 화면 맨 위. 세금 이름은 앱 바 제목으로 |
| 바텀 시트 | 손잡이, 머리(제목, 닫기), 본문, 바닥 | 언어 선택, AI 상담, 고지서 원본 보기, 문의 메모. 어떤 화면 폭에서도 아래에서 올라오는 시트. 바깥 탭, 닫기 버튼, Esc로 닫힘. 본문은 `overscroll-behavior: contain` |
| 플로팅 버튼 | 말풍선 아이콘과 "AI 상담" | 오른쪽 아래 고정. 보이는 조건은 7.2 참고 |
| 복사 버튼 | 번호 옆 36px 아이콘 버튼 | 이름은 aria-label로. 누르면 "복사했어요" 토스트 |
| 토스트 | 아래 가운데에 2.6초 | `role=status` (복사, 저장 알림) |

## 7. 패턴

### 7.1 정보 구조
```
홈
├ 시청과 주민센터 업무 > 업무 상세 (장소, 기한, 준비물) + 하단 [1345] [직원에게 보여주기]
├ 받은 고지서 읽기 > 내용 확인 + 하단 [할 일 보기] > 결과 [납부 방법 | 자주 묻는 질문 | 상담] + 하단 [위택스에서 납부하기]
├ 지원 혜택 찾기 > 혜택 상세 [자격 확인 | 준비물 | 신청 방법] + 하단 [저장] [문의 메모]
├ 생활 정보 > 항목 상세 (긴급 전화 또는 생활 팁)
└ 양주 둘러보기 > [행사 | 명소 | 맛집 | 소개] 탭

모든 화면 공통: 언어(지구본), 글자 크기(Aa), 저장한 혜택(북마크), AI 상담(플로팅 버튼)
```
- 기존 "생활 > 받을 수 있는 지원"은 홈의 "지원 혜택 찾기"와 같은 기능이어서 지웠습니다.
- 기존의 행사, 양주 소개, 맛집과 명소 화면 3개는 탭이 있는 화면 하나로 합쳤습니다.
- 담당 공무원용 창구 모드는 시민 화면에서 떼어 별도 주소로 운영합니다.

### 7.2 한 화면에 한 기능 점검표
| 기능 | 하나뿐인 진입점 | 감추는 곳 |
|---|---|---|
| 언어 변경 | 헤더 지구본 | 첫 실행 언어 화면에서는 헤더 도구를 숨김 |
| AI 상담 | 플로팅 버튼 | 하단 고정 바가 있는 화면, 고지서 흐름, 생활 상세. 이 화면들에는 전용 문의나 연락 수단이 이미 있음 |
| 저장 | 혜택 상세 하단의 "저장" 버튼, 목록 카드의 북마크 | 헤더 북마크는 저장 목록 열기 전용. 같은 아이콘이라 하단 버튼에는 글자를 함께 씀 |
| 면책과 시연 안내 | 홈 푸터에 한 번 | 하위 화면에는 두지 않음 |
| 통역 1345 | 상세 화면의 연락 행 하나 | 같은 화면에 두 번 넣지 않음 |

### 7.3 고지서 결과 화면의 정보 순서
1. 앱 바 제목: 무슨 세금인지
2. 요약 카드: 얼마인지, 언제까지인지(날짜와 D-day), 기한을 넘기면 3% 가산된다는 경고 한 줄
3. 탭 "납부 방법"(기본): 쉬운 순서로 3가지, 번호 복사 버튼
4. 탭 "자주 묻는 질문": 접이식 목록
5. 탭 "상담": 1345와 담당 부서 전화, 연체 가산금 상세, 원본 기준 안내
6. 하단 고정 바: 위택스에서 납부하기

### 7.4 한 화면 원칙
- 기준 화면은 390×740(앱 바와 하단 고정 바 포함)입니다.
- 넘칠 때 줄이는 순서: 반복 설명 문장 삭제, 요약을 위로 모으고 나머지는 탭으로, 핵심 동작은 하단 고정 바로, 목록 행 높이 56px로 압축.
- 프로토타입 기준 5개 언어 22개 화면(110개 조합) 중 106개가 스크롤 없이 들어가고, 나머지 4개도 1~35px 차이입니다.

## 8. 현지화 규칙

| 항목 | 규칙 |
|---|---|
| 지원 언어 | ko, en, zh-CN(간체), vi, ne. 양주시 외국인 주민이 많은 순서에 영어를 더함 |
| 문자열 | 모든 UI와 콘텐츠 문자열을 `[ko, en, zh, vi, ne]` 다섯 칸 배열로 관리. 빈 칸이 있으면 로드할 때 콘솔에 경고 |
| 실시간 AI 번역 | 쓰지 않음. 기존처럼 API 키가 없으면 영어로 떨어지는 구조를 만들지 않음 |
| `lang` 속성 | `<html lang>`은 고른 언어로, 한국어로 남기는 부분은 `lang="ko"`. 스크린리더 발음과 서체 선택이 이 값에 따라 달라짐 |
| 날짜 | `Intl.DateTimeFormat`으로 서식을 만들고 기간은 `formatRange`를 씀. "10.18까지" 같은 고정 문자열은 쓰지 않음. 범위 사이 구분자는 하이픈으로 통일 |

| 숫자 체계 | 네팔어도 라틴 숫자(`ne-NP-u-nu-latn`). 고지서와 전화번호를 보고 맞춰야 하기 때문 |
| ICU 폴백 | 브라우저에 해당 로캘 데이터가 없으면 Intl이 브라우저 기본 로캘(한국어)로 조용히 바뀜. 그래서 `supportedLocalesOf`로 먼저 확인하고, 없으면 `en-GB`로 대신 표시 |
| 원문 병기 | 금액과 기한 옆에 "고지서 표기: 143,000 원"처럼 한국어 원문을 함께 보여 대조를 돕기 |
| 한국어로 남기는 것 | 창구 직원용 문장, 담당자 문의 메모, 고지서 미리보기, 기관의 고유 안내(ARS 음성 안내 등) |
| 고유명사 | 로마자 표기에 필요하면 설명을 붙임. 예: Bokjiro (welfare portal), Ttokbus. 서비스 영문명 Our Yangju는 번역하지 않음 |
| 글자 길이 | 베트남어와 네팔어는 한국어보다 1.5~2배 길어짐. 버튼과 칩은 줄바꿈을 허용하고, 헤더 서비스명은 두 줄까지 보여 줌 |
| 음성 읽기 | 기기에 그 언어 음성이 없으면 재생하지 않고 안내 토스트를 띄움 |
| 번역 검수 | 중국어, 베트남어, 네팔어는 원어민과 다누리콜, 1345 통번역 상담 인력의 검수를 거친 뒤 배포 |
| 문장부호 | 가운뎃점, 엠대시, 글자 화살표를 쓰지 않음. 한국어는 "와/과", "이나", 쉼표로, 중국어는 모점(、)과 쉼표(，)로 풀어 씀 |

## 9. 접근성 (KWCAG 2.2, WCAG 2.2 AA)
- 글자 대비는 4.5:1 이상(2.2 표 참고)이고, 상태는 색 말고 글자로도 알려 줍니다.
- 아이콘 버튼마다 `aria-label`을 달고, 마우스를 올리거나 키보드로 포커스하면 툴팁을 보여 줍니다.
- 시트와 전체 화면 보기는 `role=dialog`와 `aria-modal`을 쓰고 Esc로 닫힙니다. 열리면 첫 요소로, 닫히면 원래 버튼으로 포커스가 돌아갑니다.
- 본문 바로가기 링크도 고른 언어로 바뀝니다.
- `prefers-reduced-motion`이 켜져 있으면 애니메이션을 끕니다.
- 탭을 바꿔도 스크롤 위치와 포커스를 유지하고, 새 화면으로 이동하면 앱 바 제목으로 포커스를 옮깁니다.
- 개인정보 보호를 위해 채팅과 입력창 아래에 "외국인등록번호 등 개인정보는 입력하지 마세요"를 표시하고, 고지서는 개인정보를 가린 뒤에 읽습니다.

## 10. 말투
- 한국어는 짧은 해요체로 쓰고, 한 문장에는 행동 하나만 담습니다.
- 지시보다 결과를 말합니다. 예: "복사했어요", "저장한 혜택에 담았어요".
- 법적 근거는 본문에 섞지 않고 끝에 출처 줄로 따로 씁니다. 예: "근거: 지방세기본법 제55조".
- 양주시의 공식 답변이 아니라는 점은 푸터에서 한 번만 밝힙니다.
