# 프로토타입 세금 안내 문구 (확정본)

작성: 김유진(리서치) / 기준일: 2026.10.7 / 전달: 진우(시연), 웅선(개발)
모든 문구의 근거는 「1007_유진_공개근거표」에 있음. 문구를 바꿀 때는 근거표와 같이 확인해 주세요.

## 1. 기한 경과 안내 (근거: 지방세기본법 제55조, 시행령 제34조)

- 모든 고지서에 같은 문구 (금액에 따라 문구를 바꾸지 않음)
  > 납부기한이 지나면 3%가 더해집니다. 세목별 세액이 45만 원 이상이면 이후 매월 0.66%씩 추가됩니다(최대 60개월). 정확한 금액은 위택스에서 확인하세요.
- 주의 1: 45만 원 기준은 "납세고지서별·세목별 세액"이다(제55조 제4항). "고지서 1장 합계"로 쓰지 않는다.
- 주의 2: AI가 금액을 보고 "이 고지서는 3%만"이라고 골라 말하면 세액 판정이 된다. 기준만 보여주고 판단은 위택스 확인으로 넘긴다.
- 주의 3: "매월 0.75%"는 옛 비율이므로 쓰지 않는다.

## 2. 납부 방법 (근거: 위택스봇 답변, 재산세 고지서 실물, 위택스 화면)

행동카드에는 외국인이 쉽게 할 수 있는 순서로 보여준다.

1. 위택스에서 전자납부번호로 조회 후 납부 (계좌·카드·간편결제, 00:30~23:30)
2. 은행 앱에서 고지서의 가상계좌번호로 이체
3. 은행 ATM·무인공과금기에서 카드나 통장으로 납부
4. 전화 ARS 142211 (계좌·카드)

※ ARS의 외국어 메뉴 여부는 공개 근거가 없다. 팀이 직접 전화해 확인하기 전까지 "한국어 안내"라고 쓰지 않는다. [보류]

※ 위택스 결제 단계에서 본인 인증이 필요한 것으로 확인되면 1번과 2번 순서를 바꾼다. [보류]
※ "카드 수수료 없음", "로그인 없이 결제 가능"은 확인 전까지 쓰지 않는다.

## 3. 전자납부번호 경로 안내 (근거: 위택스 납부대상조회 화면)

> **지금 할 일**
> 1. 아래 번호를 복사하세요: [전자납부번호] (복사 버튼)
> 2. 위택스(www.wetax.go.kr) → 납부 → 납부대상조회 → 전자납부번호 탭에 붙여 넣기
> 3. 보안문자 입력 → 검색 → '보기'를 눌러 납부

- AI가 고지서에서 반드시 읽어야 할 값: **세목, 금액, 납부기한, 전자납부번호, 가상계좌번호**

## 4. 감면·분할납부 문의 (부서명 없이)

> 감면과 분할납부는 세목마다 법에 정해진 기준이 다릅니다. 해당되는지 궁금하면 고지서에 적힌 담당 부서에 문의하세요.

- 서비스는 감면·분납 가능 여부를 판단하지 않는다.

## 5. 상담 연결

> 통역이 필요하면 외국인종합안내센터 ☎1345로 연락하세요.

- 고지서에 함께 적힌 031-828-9330은 양주출입국·외국인사무소 번호다.

## 6. 개인정보 안내

> 이름과 주소는 가리고, 촬영한 사진과 전자납부번호는 저장하지 않습니다.

- 전자납부번호의 처리 위치(기기 안 / 서버 전송)는 웅선 님 구현 확인 후 문구 확정. 확인 전까지 "내 화면에만"이라고 쓰지 않는다. [확인 필요]

- 시연은 개인정보가 없는 가상 고지서로만 한다.

## 7. 화면 공통 문구 (국세청 AI 챗봇 안내 방식 참고)

- 화면 하단: "이 안내는 참고용이며, 양주시의 공식 답변이 아닙니다. 정확한 내용은 위택스 또는 고지서의 담당 부서에서 확인하세요."
- 질문 입력창 위: "주민등록번호·외국인등록번호 등 개인정보는 질문에 쓰지 마세요."
- 모든 답변 아래: 그 답변의 실제 근거를 표시 (예: 가산세 → 지방세기본법 제55조 / 납부 방법 → 위택스·고지서 안내)
- 범위 밖 질문: "이 질문은 정확히 답하기 어렵습니다. ☎1345 또는 고지서의 담당 부서로 문의하세요."
